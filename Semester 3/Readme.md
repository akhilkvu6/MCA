# 🔬 Course Summaries & Repository Highlights

### 📊 20MCA201 — Data Science & Machine Learning

Covers foundational concepts of data science, exploratory data analysis, data preparation, supervised and unsupervised machine learning algorithms, and performance evaluation metrics.

* **Modules M01 – M05:**
  * **M01:** The data science process, data exploration, cleaning, statistical charting (histograms, box plots, scatter/bubble plots).
  * **M02:** Supervised learning foundations, decision trees (Entropy, Information Gain, ID3/C4.5), Naive Bayes probabilistic classifier.
  * **M03:** Regression models (simple, multiple, logistic), Support Vector Machines (SVM), hyperplanes, margin optimization, and kernels.
  * **M04:** Unsupervised learning, clustering algorithms ($K$-Means, Hierarchical), Association Rule Mining (Apriori algorithm), Dimensionality Reduction (PCA).
  * **M05:** Artificial Neural Networks (ANN), Perceptron, Backpropagation, Model Evaluation Metrics (Confusion Matrix, Precision, Recall, F1-Score, ROC/AUC).
* **Assessments & Exams:** KTU previous university question papers, Series 1 & 2 exam papers, answer keys, valuation schemes, tutorials, and student answer samples.
* **Textbooks:** *Data Science Concepts and Practice* (Vijay Kotu & Bala Deshpande) and *Machine Learning* (Dr. Krishnachandran).

### ⚡ 20MCA203 — Design & Analysis of Algorithms

Focuses on the mathematical analysis of algorithm efficiency, asymptotic notation, standard algorithm design paradigms, graph algorithms, and complexity theory.

* **Modules M01 – M05:**
  * **M01:** Analysis framework, asymptotic notations ($O, \Omega, \Theta$), recurrence relations (Master Theorem, recursion tree, substitution), Divide-and-Conquer (Merge Sort, Quick Sort, Binary Search).
  * **M02:** Greedy Technique (Fractional Knapsack, Huffman Coding, Minimum Spanning Trees — Prim's & Kruskal's, Dijkstra's Single-Source Shortest Path).
  * **M03:** Dynamic Programming (Principle of Optimality, 0/1 Knapsack, Longest Common Subsequence, Matrix Chain Multiplication, Floyd-Warshall, Bellman-Ford).
  * **M04:** Backtracking & Branch-and-Bound (N-Queens, Hamiltonian Circuit, Subset Sum, Graph Coloring, 15-Puzzle, 0/1 Knapsack Branch-and-Bound).
  * **M05:** Computational Complexity, classes $P$, $NP$, $NP$-Complete, and $NP$-Hard, Cook's Theorem, Approximation Algorithms (Vertex Cover, Metric TSP).
* **Assessments & Exams:** Past KTU semester exam papers, series examination papers, answer keys, and tutorial worksheets.
* **Textbooks:** *Introduction to Algorithms* (Cormen, Leiserson, Rivest, Stein — CLRS) and comprehensive reference guides.

### 🧪 20MCA241 — Data Science Lab

Hands-on programming laboratory in Python for data manipulation, scientific computing, visualization, and implementing classical machine learning models.

* **Numerical Computing & Data Analysis:**
  * **NumPy (`DSML Lab NumPy 01.py` – `18.py`, `E01`, `E02`):** Array creation, indexing, slicing, broadcasting, matrix arithmetic, determinant, inversion, eigenvalues, SVD.
  * **Pandas (`DSML Lab Pandas 01.py` – `12.py`, `E04`):** DataFrames, Series, missing value imputation, grouping, aggregation, CSV ingestion.
  * **Matplotlib (`DSML Lab Matplotlib 01.py` – `12.py`, `E03`):** Line graphs, bar charts, histograms, scatter plots, subplots, and exported visual figures (`Plot 01.png` – `12.png`).
* **Machine Learning Algorithms Implemented:**
  * $K$-Nearest Neighbors ($K$-NN) classification (`E05`, Jupyter notebooks)
  * Naive Bayes Gaussian & Multinomial classification (`E06`, `E08`, Python scripts & notebooks)
  * Decision Tree classification and visualization (`E07`, notebooks 01–04)
  * $K$-Means clustering (`E09`, Jupyter notebook)
  * Multiple Linear Regression (`E10`, Jupyter notebook)
  * Support Vector Machine (SVM) classification (`SVM 01.ipynb`, `SVM 02.py`)
* **Academic Records:** Certified Lab Records, Lab Manual, and Cycle 1 & 2 exercise deliverables in `Lab Documents and Records/`.

### 📱 20MCA243 — Mobile Application Development Lab

Native Android application development using **Android Studio**, **Java**, and **XML layouts**. Features 10 complete working Android applications and a publication-grade handbook.

* **Index of Practical Android Applications:**
  1. [`01_Login_Page`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/01_Login_Page): User credentials validation, clean UI, and feedback via Android `Toast`.
  2. [`02_Simple_Calculator`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/02_Simple_Calculator): Arithmetic calculator (`+`, `-`, `*`, `/`) with input validation and zero-division guards.
  3. [`03_Intent`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/03_Intent): Explicit Intent for two-activity communication and data passing via `Bundle`.
  4. [`04_Activity_Life_Cycle`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/04_Activity_Life_Cycle): Full demonstration of all 7 Android Activity lifecycle states with Logcat and UI alerts.
  5. [`05_Checkbox_and_Radiobutton`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/05_Checkbox_and_Radiobutton): Form selection handling mutually exclusive options (`RadioGroup`) and multiple choices (`CheckBox`).
  6. [`06_Implicit_Intent`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/06_Implicit_Intent): Invoking system applications: web browsing, phone dialer, email client, map coordinates, text sharing, and SMS.
  7. [`07_List_View`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/07_List_View): Dynamic collection display using `ListView` backed by an `ArrayAdapter` with click listeners.
  8. [`08_Scroll_View`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/08_Scroll_View): Vertical scrolling container dynamically loaded with programmatic views.
  9. [`09_Spinner`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/09_Spinner): Dropdown selection menu utilizing `Spinner` and `OnItemSelectedListener`.
  10. [`10_Shared_Preferences`](./20MCA243%20MOBILE%20APPLICATION%20DEVELOPMENT%20LAB/10_Shared_Preferences): Lightweight persistent storage across app restarts using `SharedPreferences`.
* **Handbook & Theory Deliverables:**
  * **Second Edition Handbook:** Publication-grade 60-page PDF covering complete Android architecture, API breakdowns, and unabridged source codes.
  * **Lab Records & Snippets:** Certified student records, source code snippets (01–10), and viva-voce examination preparation guides.

### 🛡️ 20MCA267 — Cyber Forensics (Elective III)

Covers legal, technical, and investigative principles of digital forensics, digital crime investigation processes, evidence handling, and data recovery.

* **Modules M01 – M05:**
  * **M01:** Digital evidence characteristics, rules of evidence, chain of custody, first responder procedures, search and seizure.
  * **M03:** Data acquisition methods (bit-stream copies, raw format, expert witness format), disk imaging, write blockers, forensic hardware and software tools.
  * **M04:** File systems forensics (FAT, NTFS, ext2/3/4), directory entries, deleted file recovery, data carving, steganography detection, log analysis.
  * **M05:** Network forensics, packet capture analysis, mobile device forensics, SIM card acquisition, incident response methodology, IT Act (India).
* **Technical Seminars:** Seminar presentations and technical reports on Digital Storage Systems, disk architectures, and forensic imaging.
* **Textbooks & Question Banks:** *Guide to Computer Forensics and Investigations* (Bill Nelson, Amelia Phillips, Christopher Steuart), KTU question papers, and comprehensive question banks.

📁 [Browse 20MCA267 Folder](./20MCA267%20CYBER%20FORENSICS)

### 🧠 20MCA283 — Deep Learning (Elective IV)

Covers deep neural network architectures, optimization algorithms, convolutional networks for vision, sequential models for time series/NLP, and generative models.

* **Modules M01 – M05:**
  * **M01:** Neural network foundations, forward propagation, activation functions (Sigmoid, Tanh, ReLU, Leaky ReLU, Softmax), loss functions (Cross-Entropy, MSE), backpropagation gradient computation, optimizers (SGD, Momentum, RMSprop, Adam), regularization (L1/L2, Dropout, Batch Normalization).
  * **M02:** Convolutional Neural Networks (CNNs), convolution operation, padding, stride, pooling layers, classic vision architectures (LeNet, AlexNet, VGGNet, ResNet skip connections).
  * **M03:** Deep network training dynamics, vanishing and exploding gradients, learning rate schedules, transfer learning, fine-tuning pretrained models.
  * **M04:** Recurrent Neural Networks (RNN), BPTT (Backpropagation Through Time), Long Short-Term Memory (LSTM) cells (input, forget, output gates), Gated Recurrent Units (GRU), Sequence-to-Sequence models.
  * **M05:** Autoencoders (undercomplete, denoising, sparse), Variational Autoencoders (VAE), Generative Adversarial Networks (GANs: Generator, Discriminator, minimax loss, DCGAN).
* **Assessments & Seminars:** Series 1 & 2 exam papers, assignments, valuation schemes, tutorials, model question papers, and technical seminars on Prompt Engineering.
* **Textbooks:** *Generative Deep Learning* (David Foster, O'Reilly).
