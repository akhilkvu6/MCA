2. Fundamental Formulas & Target Class Entropy

1. Entropy Formula:

$$\text{Entropy}(S) = -\sum_{i=1}^{c} p_i \log_2(p_i)$$

2. Information Gain Formula:

$$\text{Gain}(S, A) = \text{Entropy}(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} \text{Entropy}(S_v)$$

Step 1: Calculate Target Class Entropy for Dataset T

Target Class (Job Offer) distribution: Yes = 7, No = 3 (Total = 10)

$$\text{Entropy(Target Attribute = Job Offer)} = \text{Entropy}(7, 3) = -\left[\frac{7}{10}\log_2\left(\frac{7}{10}\right) + \frac{3}{10}\log_2\left(\frac{3}{10}\right)\right]$$ $$= -(-0.3599 + -0.5208) = \mathbf{0.8807}$$
