Decision Tree Induction: Core Theory

Definitions, Tree Anatomy, Induction Steps & Attribute Selection Measures

1. Definition & Structural Anatomy

A Decision Tree is a non-parametric supervised learning model used for both Classification and Regression tasks. It represents decision logic through a hierarchical flowchart structure:

  • Root Node: Topmost node evaluating the single attribute with the highest predictive value.
  • Internal / Decision Nodes: Intermediate nodes evaluating conditions on individual attributes.
  • Branches: Outgoing pathways representing outcomes of attribute tests.
  • Leaf / Terminal Nodes: Bottom-most nodes holding final target class predictions (no further splitting).

2. Decision Tree Induction Steps (ID3 Algorithm)

  1. Calculate Base Entropy: Compute target entropy across the entire training set $S$.
  2. Evaluate Attributes: For each candidate attribute $A$, compute conditional entropies for all its value subsets and calculate Information Gain $\text{Gain}(S, A)$.
  3. Select Best Split: Pick the attribute with the Maximum Information Gain as the current decision node.
  4. Branch Creation: Create an outgoing branch for each distinct value of the selected attribute.
  5. Recursive Splitting & Base Cases:
    • If a branch subset is pure → Create a Leaf Node with that class label.
    • If no attributes remain → Create a Leaf Node assigned to the majority class.
    • Otherwise → Recursively repeat steps 1–4 on the remaining branch subset.

Stopping Criteria:

  • All instances at a node belong to the exact same class ($\text{Entropy} = 0$).
  • No remaining candidate attributes are available for further branching.
  • No instances remain for a given branch value.

3. Attribute Selection Measures (ASM)

Entropy (Impurity Measure):

$$\text{Entropy}(S) = -\sum_{i=1}^{c} p_i \log_2(p_i)$$

Information Gain (ID3 Metric):

$$\text{Gain}(S, A) = \text{Entropy}(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} \text{Entropy}(S_v)$$

Gini Impurity (CART Metric):

$$\text{Gini}(S) = 1 - \sum_{i=1}^{c} p_i^2$$
