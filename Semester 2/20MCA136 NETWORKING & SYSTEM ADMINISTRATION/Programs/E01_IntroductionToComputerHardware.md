# 📘 Introduction

Computer hardware refers to the physical parts of a computer system that can be seen and touched. These components work together to process information, store data, and communicate with external devices.

Computer hardware mainly includes:

* Input Devices
* Output Devices
* CPU
* RAM
* Storage Devices
* Motherboard
* Power Supply
* Expansion Cards
* Ports and Connectors

Understanding hardware is essential for:

* system administration
* troubleshooting
* networking
* maintenance
* virtualization
* hardware upgrades

---

# ⌨️ 1. Input Devices

Input devices are hardware components used to enter data and instructions into the computer system. 

## 📌 Common Input Devices

### 🖱️ Mouse

Used to control the pointer on the screen and perform operations like click, drag, and scroll.

### ⌨️ Keyboard

Used to type text, numbers, and commands into the computer.

### 📄 Scanner

Converts physical documents and images into digital format.

### 🔍 OCR (Optical Character Recognition)

Reads printed text from paper and converts it into editable digital text.

### 🏦 MICR (Magnetic Ink Character Recognition)

Used in banks for reading cheque numbers printed with magnetic ink.

### 🎮 Joystick

Used mainly in games and simulations to control movement.

### 📦 Barcode Reader

Reads barcodes using laser or imaging technology.

### 🖐️ Touchpad

Used mainly in laptops for cursor movement.

### 🎯 Trackball

Input device where the user rotates a ball to move the pointer.

---

# 🖨️ 2. Output Devices

Output devices display processed information from the computer to the user. 

## 📌 Common Output Devices

### 🖥️ Monitor

Displays text, images, videos, and graphical output.

### 🖨️ Printer

Produces hard copies of digital documents.

### 📽️ Multimedia Projector

Projects computer display onto a large screen.

### 📐 Plotter

Used for printing engineering and architectural drawings.

### 🎞️ Microfilm

Stores images of documents in miniature photographic form.

---

# ⚙️ 3. Role of Software

Software controls and operates the computer hardware. 

## 📌 Types of Software

### 🧩 System Software

Controls hardware operations.

Examples:

* Operating System
* Device Drivers
* Utility Programs

### 📱 Application Software

Used for performing user tasks.

Examples:

* MS Word
* Browsers
* Media Players

---

# 🔌 4. SMPS (Switched Mode Power Supply)

SMPS converts AC power from the wall outlet into regulated DC power required by computer components. 

## 📌 Functions

* Supplies power to motherboard
* Powers CPU, RAM, HDD, GPU
* Protects system from voltage fluctuations

## 📌 Advantages

* High efficiency
* Less heat generation
* Compact size

---

# 💾 5. RAM (Random Access Memory)

RAM is the primary memory of the computer used for temporary storage. 

## 📌 Features

* Volatile memory
* Fast access speed
* Stores running programs and active data

## 📌 Types of RAM

### 🔹 SRAM

Static RAM used in cache memory.

### 🔹 DRAM

Dynamic RAM used as main memory.

### 🔹 SDRAM

Synchronous DRAM synchronized with CPU clock.

### 🔹 DDR RAM

Double Data Rate RAM with higher speed versions:

* DDR
* DDR2
* DDR3
* DDR4

## 📌 Advantages

* Fast performance
* Improves multitasking

## 📌 Disadvantage

* Data lost when power is OFF

# 🧠 7. Processor (CPU)

CPU is the brain of the computer system. 

## 📌 Functions

* Executes instructions
* Performs calculations
* Controls hardware operations

## 📌 Components

### ➕ ALU (Arithmetic Logic Unit)

Performs arithmetic and logical operations.

### 🎮 Control Unit

Controls execution of instructions.

### 🗂️ Registers

Temporary high-speed storage inside CPU.

---

# 💽 8. Hard Disk Drive (HDD)

HDD is a magnetic storage device used for permanent data storage. 

## 📌 Features

* Large storage capacity
* Non-volatile memory
* Uses spinning magnetic disks

## 📌 Advantages

* Low cost
* High storage capacity

## 📌 Disadvantages

* Slower than SSD
* Mechanical damage possible

---

# ⚡ 9. SSD (Solid State Drive)

SSD stores data using flash memory chips. 

## 📌 Advantages

* Faster boot speed
* No moving parts
* Lower power consumption
* Durable

## 📌 Disadvantages

* Higher cost

---

# 🎮 10. Graphics Card (GPU)

GPU processes graphical and video data. 

## 📌 Uses

* Gaming
* Video editing
* 3D rendering
* Machine learning
* Cryptocurrency mining

## 📌 Advantage

Processes graphics faster than CPU.

---

# 🔌 11. Ports and Connectors

Ports are interfaces used to connect external devices. 

## 📌 Types of Ports

### 🔹 USB Port

Used for connecting:

* keyboard
* mouse
* pendrive
* printer

### 🔹 Ethernet Port

Used for wired networking.

### 🔹 VGA Port

Used for video display output.

### 🔹 HDMI Port

Transfers high-quality audio and video.

### 🔹 PS/2 Port

Old keyboard and mouse connector.

### 🔹 Serial Port

Used for older communication devices.

### 🔹 Parallel Port

Used mainly for old printers.

---

# 🔊 12. Audio Connectors

Audio connectors are used for sound input and output. 

| Color  | Function         |
| ------ | ---------------- |
| Green  | Speaker output   |
| Pink   | Microphone       |
| Blue   | Line input       |
| Black  | Rear speaker     |
| Orange | Center/Subwoofer |

---

# 🖥️ 13. Motherboard

Motherboard is the main circuit board connecting all hardware components. 

## 📌 Components

### 🧠 CPU Socket

Holds the processor.

### 💾 RAM Slots

Used to install RAM modules.

### 🎮 PCI Slots

Used for expansion cards.

### 🔋 CMOS Battery

Stores BIOS settings.

### 🔌 SATA Connector

Connects storage devices.

### 🧩 AGP Slot

Used for graphics cards in older systems.

---

# 🔋 14. CMOS Battery

CMOS battery stores BIOS configuration settings. 

## 📌 Stores

* Date and time
* CPU details
* RAM information
* Hard disk settings
* Boot settings

---

# 🧩 15. Expansion Bus

Expansion buses connect additional cards to the motherboard. 

## 📌 Examples

* Network Card
* Audio Card
* Graphics Card

---

# 🔗 16. IDE and SATA

Used for connecting storage devices. 

## 📌 IDE

* Older technology
* Ribbon cable
* Slower speed

## 📌 SATA

* Faster technology
* Thin cable
* Better airflow

---

# 🌉 17. North Bridge and South Bridge

Chipset components controlling motherboard communication. 

## 📌 North Bridge

Handles:

* CPU communication
* RAM communication
* Graphics communication

## 📌 South Bridge

Handles:

* USB
* Audio
* SATA
* Input/output operations
