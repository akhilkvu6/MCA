# 📘 Semester 1

### 🐍 20MCA131 — Programming Lab

Python programming exercises covering fundamental programming concepts, functions, modules, object-oriented programming, file handling, CSV processing, and related practical exercises.

📁 [Open Programming Lab](./Semester%201/20MCA131%20PROGRAMMING%20LAB)

### 🌐 20MCA133 — Web Programming Lab

Web programming exercises and PHP-based applications, including practical web development programs.

📁 [Open Web Programming Lab](./Semester%201/20MCA133%20WEB%20PROGRAMMING%20LAB)

### 🌳 20MCA135 — Data Structures Lab

Practical implementations of data structures and algorithms using C.

Topics include:

* Arrays
* Stacks
* Queues
* Linked Lists
* Circular Linked Lists
* Binary Search Trees
* Kruskal's Algorithm
* Prim's Algorithm
* Topological Sorting
* DFS
* BFS

📁 [Open Data Structures Lab](./Semester%201/20MCA135%20DATA%20STRUCTURES%20LAB)
